# FamilyOS Pack

**Package code:** `family_os`  
**Brief:** [docs/novixa/03-solution/family-os-pack-brief-v1.md](../../../../docs/novixa/03-solution/family-os-pack-brief-v1.md)

**FamilyOS Starter** — One Family. One Plan. One Daily Flow.

Helps nuclear families (children ages 4–17) coordinate daily life through:

- **Routine** — life rhythm templates  
- **Commitment** — responsibilities/habits (not corporate “tasks”)  
- **Progress** — shared daily completion on a Day Flow  

Does **not** manage finance, health, GPS, school LMS, or child surveillance.

Pharmacy `family_members` (care wallet) remains a separate channel concept.
